## 200M峰值带宽和3M固定带宽，实际差在哪？

一个是峰值、一个是固定，数字上差了六十多倍，但不能直接画等号。

3M固定带宽的实际下载速度上限约384KB/s（3Mbps除以8换算），特点是稳，高峰期不掉速，放企业官网、博客、API服务这种流量平稳的业务刚好。

200Mbps是峰值带宽，理论最高能到25MB/s左右，适合有大文件下载、图片较多或流量波动明显的场景。代价是它属于共享出口，高峰期未必能跑满标称值。

选择逻辑就两条：业务流量平稳、要稳定，选99元ECS的3M固定；有突发大流量需求、下载场景多，选38元轻量的200M峰值。
